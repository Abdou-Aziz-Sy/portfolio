## Décisions

<DecisionRecord
  numero="01"
  titre="Un modèle de langage auto-hébergé plutôt qu'une API"
  contexte="Les dossiers de candidature contiennent des pièces à extraire sans ressaisie manuelle. Les services tiers payants sont exclus du projet."
  options={[
    { libelle: "API de modèle hébergée", note: "exclue : payante" },
    { libelle: "Règles sur le texte OCR", note: "fragiles d'un formulaire à l'autre" },
    { libelle: "Petit modèle auto-hébergé couplé à l'OCR", retenue: true },
  ]}
  decision="Un petit modèle de langage tourne sur la machine virtuelle, dans son propre conteneur, et reçoit le texte produit par l'OCR."
  consequences="Aucun coût par requête, aucune donnée qui sort du serveur. Compromis assumé entre taille du modèle et temps de réponse."
/>

<DecisionRecord
  numero="02"
  titre="Server-Sent Events plutôt que WebSocket"
  contexte="Les agents doivent voir arriver les notifications sans recharger la page. Le flux ne va que du serveur vers le navigateur."
  options={[
    { libelle: "WebSocket", note: "bidirectionnel, inutile ici" },
    { libelle: "Interrogation périodique", note: "charge et latence inutiles" },
    { libelle: "Server-Sent Events", retenue: true },
  ]}
  decision="Les notifications passent par un flux text/event-stream servi par l'API Express."
  consequences="SSE traverse Nginx et les proxys sans configuration particulière et coûte moins cher à exploiter. À revoir si un besoin bidirectionnel apparaît."
/>

<DecisionRecord
  numero="03"
  titre="Des tests bout en bout plutôt que des tests unitaires"
  contexte="Il fallait vérifier les parcours réels — routes, rôles, base de données — et empêcher le retour des incidents de production."
  options={[
    { libelle: "Tests unitaires d'abord", note: "loin des incidents réels" },
    { libelle: "Tests bout en bout de l'API", retenue: true },
  ]}
  decision="Treize domaines de l'API sont couverts de bout en bout, contrôles d'accès inclus."
  consequences="Les incidents de production ont donné lieu à des cas de non-régression. Contrepartie : des suites plus lentes, et des tests unitaires à poser plus tôt."
/>
