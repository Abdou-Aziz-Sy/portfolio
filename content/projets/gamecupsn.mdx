## Contexte

<Prose>
Une plateforme pour organiser des tournois Valorant au Sénégal : inscription des équipes, arbres de tournoi, palmarès publics. Le projet est mené à trois, et chaque décision de cadrage est écrite et datée dans le dépôt.
</Prose>

## Architecture

<Prose>
Un front React construit avec Vite, une API Express en TypeScript et une base PostgreSQL. Le modèle de données sépare l'identité des joueurs de leurs données de jeu, pour pouvoir accueillir d'autres jeux sans refonte.
</Prose>
